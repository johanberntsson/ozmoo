# Ozmoo Apple IIgs font: 3x8 in a 4-wide cell.
#
# The 1-bit 320-mode font: 80 columns of a 320-pixel screen is 4 pixels per
# character cell, so the glyph is 3 pixels wide with one blank column of gap.
# Three pixels will not carry a seven-row body, so this is a five-row design
# (rows 1-5, baseline row 5) with descenders in row 6 and rows 0 and 7 blank -
# the extra line spacing is part of what makes a font this narrow readable.
#
# Drawn for Ozmoo, September 2026 - not derived from any ROM font.
#
# Format: @<hex code>, then 8 rows of 4 columns, '#' ink and '.' paper.
