# Ozmoo Apple IIgs font: 3x8 greyscale, in a 4-wide cell.
#
# The 1-bit gs-3x8.txt with greys added at the handful of places where three
# pixels cannot carry the shape.  This is what "the 4 samples get 16 colours
# each, so the font can be antialiased" is actually worth: area-averaging a
# wider master is no good (every one-pixel stem comes out half lit and the whole
# font loses contrast), but spending a grey on the middle stem of m/M/w/W - the
# letters that need five columns and have three - buys back the shapes a 1-bit
# 3-wide font has to give up.  Nothing else in the set needs one.
#
# Shades: '.' paper, '-' one third, '+' two thirds, '#' ink.  Four palette
# entries with the inverse-video swap included, since 1-x maps the set onto
# itself.
#
# Drawn for Ozmoo, September 2026 - not derived from any ROM font.
#
# Format: @<hex code>, then 8 rows of 4 columns.
